### TOOL-HOME-FOLDER-ANALYSIS.PS1(DEV)
Genera un informe sobre las carpetas HOME de los usuarios. Ejemplo: permisos NTFS o el tamaño de la carpeta del usuario. También hay validación de acceso.

### TOOL-HYPERV-INVENTORY.PS1(DEV)
Genera un informe sobre el rendimiento y el estado del hardware de las máquinas virtuales en un host Hyper-V.

### TOOL-PRINTSERVER-INVENTORY-SMTP-REPORT.PS1(DEV)
El script crea un informe Excel de los servidores de impresión y envía el informe por correo electrónico.

### TOOL-STORAGE-GET-REMOTEVMDISKUSAGE.PS1
Esta función se creó para analizar el espacio usado por un equipo remoto. Calcula cada disco y el espacio total usado.
