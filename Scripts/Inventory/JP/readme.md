### TOOL-HOME-FOLDER-ANALYSIS.PS1(DEV)
ユーザーの HOME フォルダーに関するレポートを作成します。例: NTFS アクセス許可やユーザーフォルダーのサイズ。アクセス検証もあります。

### TOOL-HYPERV-INVENTORY.PS1(DEV)
Hyper-V ホスト上の仮想マシンのパフォーマンスとハードウェア状態に関するレポートを作成します。

### TOOL-PRINTSERVER-INVENTORY-SMTP-REPORT.PS1(DEV)
印刷サーバーの Excel レポートを作成し、メールで送信します。

### TOOL-STORAGE-GET-REMOTEVMDISKUSAGE.PS1
この関数はリモートコンピューターの使用容量を分析するために作成されました。各ディスクと合計使用容量を計算します。
