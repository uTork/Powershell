### Exchange_basic_command.ps1
Contient les commandes Exchange Online courantes

### Final_Script_Auto_assign_365license.ps1
Assigne automatiquement la licence 365 selon l'appartenance au groupe d'utilisateurs Active Directory.

### Set_AD_USER_PROXYADDRESS.ps1
Définit l'attribut proxyAddress pour Office 365. L'attribut ressemble à SMTP:ssss@sss.com

### connect_Exchange_online.ps1
Connecte votre session PowerShell à votre service Exchange Online

### create_shared_mailbox.ps1
Crée une boîte aux lettres partagée avec les droits dans Exchange Online

### send_1000_mailmessage.ps1
Envoie 1000 messages à chaque boîte aux lettres pour créer des courriels fictifs pour les tests.

### azure_ad_sync.ps1
Commande de synchronisation Azure Active Directory
