### Exchange_basic_command.ps1
よく使う Exchange Online コマンドを含みます

### Final_Script_Auto_assign_365license.ps1
Active Directory ユーザーグループのメンバーシップに基づき 365 ライセンスを自動割り当てします。

### Set_AD_USER_PROXYADDRESS.ps1
Office 365 用の proxyAddress 属性を設定します。属性は SMTP:ssss@sss.com の形式です

### connect_Exchange_online.ps1
PowerShell セッションを Exchange Online サービスに接続します

### create_shared_mailbox.ps1
Exchange Online で権限付きの共有メールボックスを作成します

### send_1000_mailmessage.ps1
テスト用の偽メール作成のため、各メールボックスに 1000 通送信します。

### azure_ad_sync.ps1
Azure Active Directory 同期コマンド
