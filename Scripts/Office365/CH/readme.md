### Exchange_basic_command.ps1
包含常用的 Exchange Online 命令

### Final_Script_Auto_assign_365license.ps1
根据 Active Directory 用户组成员身份自动分配 365 许可证。

### Set_AD_USER_PROXYADDRESS.ps1
设置 Office 365 的 proxyAddress 属性。属性形如 SMTP:ssss@sss.com

### connect_Exchange_online.ps1
将 PowerShell 会话连接到 Exchange Online 服务

### create_shared_mailbox.ps1
在 Exchange Online 中创建带权限的共享邮箱

### send_1000_mailmessage.ps1
向每个邮箱发送 1000 封邮件以创建用于测试的虚假邮件。

### azure_ad_sync.ps1
Azure Active Directory 同步命令
