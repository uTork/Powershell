### Exchange_basic_command.ps1
Contiene comandos comunes de Exchange Online

### Final_Script_Auto_assign_365license.ps1
Asigna la licencia 365 automáticamente según la membresía del grupo de usuarios de Active Directory.

### Set_AD_USER_PROXYADDRESS.ps1
Establece el atributo proxyAddress para Office 365. El atributo tiene el formato SMTP:ssss@sss.com

### connect_Exchange_online.ps1
Conecta su sesión de PowerShell a su servicio Exchange Online

### create_shared_mailbox.ps1
Crea un buzón compartido con derechos en Exchange Online

### send_1000_mailmessage.ps1
Envía 1000 mensajes a cada buzón para crear correo falso para pruebas.

### azure_ad_sync.ps1
Comando de sincronización de Azure Active Directory
