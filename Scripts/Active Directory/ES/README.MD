### TOOL-AD-SET-ADUSERTSPROFILE.PS1
Esta función permite cambiar la ruta del perfil de terminal server en los usuarios miembros de un grupo de Active Directory. Esta función se utilizará en una tarea programada.

### Reboot-Computer.PS1 (DEV)
Reinicio de una lista de servidores basada en una palabra clave en Active Directory

### TOOL-AD-SYNC-GROUP-MEMBERS.PS1
El script fue creado para sincronizar los miembros del grupo domain users hacia otro grupo de Active Directory. La función se usa en una tarea programada que se ejecuta cada 15 minutos. Cuando un usuario se agrega al grupo "domain users" por ejemplo. El usuario se sincroniza cuando se ejecuta la tarea programada.

### TOOL-AD-USER-INACTIVE.PS1 (DEV)
Buscar usuarios inactivos en Active Directory

### TOOL-AD-REMOVE-DISABLED-USERS-FROM-ALL-GROUP.PS1
Eliminar usuarios deshabilitados de todos los grupos de Active Directory.

### TOOL-AD-SET-COMPUTER-DESCRIPTION.PS1
Establecer la descripción del objeto equipo en Active Directory a partir de una hoja de Excel.

### TOOL-GPUPDATE-REMOTE.PS1
Ejecutar GPUPDATE de forma silenciosa en equipos remotos listados en Active Directory.

### Batch_user_creation_basic
Creación por lotes de usuarios de Active Directory a partir de un archivo CSV.

### Create Test Environements
Herramientas para crear entornos de prueba de Active Directory: unidades organizativas, usuarios, grupos, carpetas de inicio y listas de nombres.
