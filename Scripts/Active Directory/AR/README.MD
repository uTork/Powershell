### TOOL-AD-SET-ADUSERTSPROFILE.PS1
تتيح هذه الدالة تغيير مسار ملف تعريف خادم الطرفية للمستخدمين الأعضاء في مجموعة Active Directory. ستُستخدم هذه الدالة في مهمة مجدولة.

### Reboot-Computer.PS1 (DEV)
إعادة تشغيل قائمة خوادم بناءً على كلمة مفتاحية في Active Directory

### TOOL-AD-SYNC-GROUP-MEMBERS.PS1
تم إنشاء هذا البرنامج النصي لمزامنة أعضاء مجموعة domain users مع مجموعة Active Directory أخرى. تُستخدم الدالة في مهمة مجدولة تعمل كل 15 دقيقة. عندما يُضاف مستخدم إلى مجموعة "domain users" على سبيل المثال، تتم المزامنة عند تنفيذ المهمة المجدولة.

### TOOL-AD-USER-INACTIVE.PS1 (DEV)
البحث عن المستخدمين غير النشطين في Active Directory

### TOOL-AD-REMOVE-DISABLED-USERS-FROM-ALL-GROUP.PS1
إزالة المستخدمين المعطلين من جميع مجموعات Active Directory.

### TOOL-AD-SET-COMPUTER-DESCRIPTION.PS1
تعيين وصف كائن الكمبيوتر في Active Directory من ورقة Excel.

### TOOL-GPUPDATE-REMOTE.PS1
تشغيل GPUPDATE بصمت على أجهزة الكمبيوتر البعيدة المدرجة في Active Directory.

### Batch_user_creation_basic
إنشاء مستخدمي Active Directory دفعة واحدة من ملف CSV.

### Create Test Environements
أدوات لإنشاء بيئات اختبار Active Directory: وحدات تنظيمية، مستخدمون، مجموعات، مجلدات رئيسية وقوائم أسماء.
