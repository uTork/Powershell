### TOOL-AD-SET-ADUSERTSPROFILE.PS1
This function allows you to change the path of the terminal server profile on users who are members of an Active Directory group. This function will be used in a scheduled task.

### Reboot-Computer.PS1 (DEV)
Restarting a keyword-based server list in Active Directory

### TOOL-AD-SYNC-GROUP-MEMBERS.PS1
The script was created to synchronize the members of the domain users group to another active directory group. The function is used in a scheduled task that runs every 15 minutes. When a user is added to the "domain users" group for example. The user synchronizes when the schedule task is executed.

### TOOL-AD-USER-INACTIVE.PS1 (DEV)
Search for inactive users in Active Directory

### TOOL-AD-REMOVE-DISABLED-USERS-FROM-ALL-GROUP.PS1
Remove disabled users from all Active Directory groups.

### TOOL-AD-SET-COMPUTER-DESCRIPTION.PS1
Set the computer object description in Active Directory from an Excel sheet.

### TOOL-GPUPDATE-REMOTE.PS1
Run GPUPDATE silently on remote computers listed in Active Directory.

### Batch_user_creation_basic
