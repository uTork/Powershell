### TOOL-AD-SET-ADUSERTSPROFILE.PS1
Ця функція дозволяє змінити шлях профілю термінального сервера для користувачів, які є членами групи Active Directory. Ця функція використовуватиметься в запланованому завданні.

### Reboot-Computer.PS1 (DEV)
Перезапуск списку серверів на основі ключового слова в Active Directory

### TOOL-AD-SYNC-GROUP-MEMBERS.PS1
Скрипт створено для синхронізації членів групи domain users з іншою групою Active Directory. Функція використовується в запланованому завданні, яке виконується кожні 15 хвилин. Коли користувача додано до групи "domain users", наприклад. Користувач синхронізується під час виконання запланованого завдання.

### TOOL-AD-USER-INACTIVE.PS1 (DEV)
Пошук неактивних користувачів в Active Directory

### TOOL-AD-REMOVE-DISABLED-USERS-FROM-ALL-GROUP.PS1
Видалення вимкнених користувачів з усіх груп Active Directory.

### TOOL-AD-SET-COMPUTER-DESCRIPTION.PS1
Встановити опис об'єкта комп'ютера в Active Directory з аркуша Excel.

### TOOL-GPUPDATE-REMOTE.PS1
Запустити GPUPDATE у фоновому режимі на віддалених комп'ютерах зі списку Active Directory.

### Batch_user_creation_basic
Пакетне створення користувачів Active Directory з CSV-файлу.

### Create Test Environements
Інструменти для створення тестових середовищ Active Directory: організаційні підрозділи, користувачі, групи, домашні папки та списки імен.
