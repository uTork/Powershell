### TOOL-AD-SET-ADUSERTSPROFILE.PS1
פונקציה זו מאפשרת לשנות את נתיב פרופיל שרת המסוף עבור משתמשים החברים בקבוצת Active Directory. הפונקציה תשמש במשימה מתוזמנת.

### Reboot-Computer.PS1 (DEV)
הפעלה מחדש של רשימת שרתים על בסיס מילת מפתח ב-Active Directory

### TOOL-AD-SYNC-GROUP-MEMBERS.PS1
הסקריפט נוצר כדי לסנכרן את חברי קבוצת domain users לקבוצת Active Directory אחרת. הפונקציה משמשת במשימה מתוזמנת שרצה כל 15 דקות. כאשר משתמש מתווסף לקבוצת "domain users" לדוגמה. המשתמש מסונכרן כאשר המשימה המתוזמנת רצה.

### TOOL-AD-USER-INACTIVE.PS1 (DEV)
חיפוש משתמשים לא פעילים ב-Active Directory

### TOOL-AD-REMOVE-DISABLED-USERS-FROM-ALL-GROUP.PS1
הסרת משתמשים מושבתים מכל קבוצות Active Directory.

### TOOL-AD-SET-COMPUTER-DESCRIPTION.PS1
הגדרת תיאור אובייקט המחשב ב-Active Directory מגיליון Excel.

### TOOL-GPUPDATE-REMOTE.PS1
הפעלת GPUPDATE בשקט במחשבים מרוחקים הרשומים ב-Active Directory.

### Batch_user_creation_basic
יצירת משתמשים ב-Active Directory באצווה מקובץ CSV.

### Create Test Environements
כלים ליצירת סביבות בדיקה של Active Directory: יחידות ארגוניות, משתמשים, קבוצות, תיקיות בית ורשימות שמות.
