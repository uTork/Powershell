### TOOL-AD-SET-ADUSERTSPROFILE.PS1
この関数は、Active Directory グループのメンバーであるユーザーのターミナルサーバープロファイルのパスを変更できます。この関数はスケジュールされたタスクで使用されます。

### Reboot-Computer.PS1 (DEV)
Active Directory のキーワードに基づくサーバーリストの再起動

### TOOL-AD-SYNC-GROUP-MEMBERS.PS1
このスクリプトは、domain users グループのメンバーを別の Active Directory グループに同期するために作成されました。この関数は 15 分ごとに実行されるスケジュール済みタスクで使用されます。たとえばユーザーが "domain users" グループに追加されると、スケジュール済みタスクの実行時に同期されます。

### TOOL-AD-USER-INACTIVE.PS1 (DEV)
Active Directory で非アクティブなユーザーを検索

### TOOL-AD-REMOVE-DISABLED-USERS-FROM-ALL-GROUP.PS1
無効化されたユーザーをすべての Active Directory グループから削除します。

### TOOL-AD-SET-COMPUTER-DESCRIPTION.PS1
Excel シートから Active Directory のコンピューターオブジェクトの説明を設定します。

### TOOL-GPUPDATE-REMOTE.PS1
Active Directory に登録されたリモートコンピューターで GPUPDATE をサイレント実行します。

### Batch_user_creation_basic
CSV ファイルから Active Directory ユーザーを一括作成します。

### Create Test Environements
Active Directory テスト環境を作成するツール：組織単位、ユーザー、グループ、ホームフォルダー、名前リスト。
