### TOOL-AD-SET-ADUSERTSPROFILE.PS1
Cette fonction permet de changer le path du profile terminal serveur sur les utilisateurs membres d'un groupe Active Directory. Cette fonction sera utilisée dans une tâche planifiée.

### Reboot-Computer.PS1 (DEV)
Redémarrage d'une liste de serveurs basé sur un mot clé dans Active Directory

### TOOL-AD-SYNC-GROUP-MEMBERS.PS1
Le script a été créé pour synchroniser les membres du groupe domain users vers un autre groupe Active Directory. La fonction sert dans une tâche planifiée qui s'exécute à toutes les 15 minutes. Quand un utilisateur est ajouté au groupe "domain users" par exemple. L'utilisateur se synchronise quand la tâche planifiée s'exécute.

### TOOL-AD-USER-INACTIVE.PS1 (DEV)
Recherche les utilisateurs inactifs dans Active Directory

### TOOL-AD-REMOVE-DISABLED-USERS-FROM-ALL-GROUP.PS1
Retire les utilisateurs désactivés de tous les groupes Active Directory.

### TOOL-AD-SET-COMPUTER-DESCRIPTION.PS1
Mettre la description de l'objet ordinateur dans Active Directory à partir d'une feuille Excel.

### TOOL-GPUPDATE-REMOTE.PS1
Exécuter GPUPDATE en silence sur des ordinateurs distants listés dans Active Directory.

### Batch_user_creation_basic
Création en lot d'usagers Active Directory à partir d'un fichier CSV.

### Create Test Environements
Outils pour créer des environnements de test Active Directory : unités d'organisation, usagers, groupes, dossiers personnels et listes de noms.
